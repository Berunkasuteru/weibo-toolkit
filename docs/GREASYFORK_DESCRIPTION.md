# Weibo Toolkit

一个本地优先的微博桌面网页版工具箱：给熟悉的人留下私人备注，记录接口可见的关系变化，查看粉丝快照，导出当前私信会话，并按需改善浏览体验。

界面以中文为主。没有项目服务器、遥测或云同步；可选页面功能和使用统计默认关闭。

## v0.10.0：友人档案现在可以在信息流里用了

“去年摄影展认识的阿岚，喜欢拍海边。”

给一个账号写下这样的私人备注，再加上“摄影”“熟人”等标签。档案绑定稳定 UID，对方改名后备注仍在，同名的两个人也不会混在一起。

- 在工具箱的 **友人档案** 中浏览、搜索、按标签筛选、编辑或删除。
- 可选在他人主页显示档案，也可在首页和“最新微博”的作者旁显示一个小书签。
- 点书签先查看，主动选择添加或编辑后才进入表单；没有实际修改时可直接关闭。
- 原创、有评语转发与没有评语的纯转发，都以外层作者为目标；无法可靠识别 UID 时跳过。
- 备注正文和已有的本地昵称记录在卡片内查看，信息流保持简洁。
- **Backup v3** 一并备份备注与标签；旧 v1/v2 备份仍可恢复，且不会清空已有友人档案。

开启位置：**工具箱 → 浏览体验 → 增强 → 在主页显示友人档案／在信息流显示友人档案**。两项默认关闭，互相独立，不需要开启其他页面增强。

## 还有哪些功能

### 关系雷达

比较成功的 API 可见关注快照，记录账号出现、消失、互相关注状态与昵称变化。首次更新只建立基线。可按昵称或 UID 搜索事件，查看个人时间线，并导出 CSV 或 Markdown。

“从可见列表消失”只表示接口不再返回，不等于确定取关、拉黑或销号。互相关注变化也只覆盖可见关注列表中的账号。

### 粉丝快照与体检

保存接口当前返回的粉丝快照，记录后续可见变化。体检基于已有快照，在本地按公开数值、认证、注册日期、关注来源等事实筛选；未知值不会当成零，也不会给账号贴“机器人”等判断标签。

支持单个或当前页所选粉丝的移除，每次明确确认；每批最多 50 个，顺序执行，成功后约等待 3 秒，不自动重试，遇到失败或结果无法确认即停止。**这是会修改真实微博关系、且无法自动撤销的操作。**

### 私信 Markdown 导出

手动打开一个普通一对一会话后，导出接口当时实际返回的可访问历史。保留消息顺序、正文、时间语义及图片、链接等标记。

不遍历全部会话，不支持群聊，不下载媒体，不发送、删除或恢复消息。导出是本地明文，正文可能包含个人信息；Toolkit 本身不调用 AI API。

### 可选浏览增强

首页优先进入“最新微博”、保守推广过滤、可选强力规则、自动展开原创长微博，以及隐藏热搜、侧栏和顶部部分入口。全部默认关闭，可随时调整。强力过滤可能误伤；转发微博不会被自动展开。

### 主页小档案与计步器

主页小档案复用本地关系数据，展示已记录昵称与关系信息，并可记录本地访问足迹。计步器估算活跃时间与不同微博数量，统计仅保存在当前浏览器。两者默认关闭，与友人档案独立。

### 可选自动更新

关系雷达和粉丝快照可分别开启自动更新。它只在打开或刷新桌面微博页面后检查，不是后台服务，不持续轮询，不会自动移除粉丝。

## 安装与使用

1. 使用桌面浏览器，安装 Tampermonkey 或兼容用户脚本管理器。
2. 安装本脚本，登录并刷新 `https://weibo.com/`。
3. 点击右下角 **Weibo Toolkit**。用户脚本菜单里也有后备入口。
4. 关系雷达与粉丝快照需要成功更新后才有基线；友人档案不需要先建关系基线。
5. 页面增强在 **浏览体验** 中按需开启。

升级请更新原有脚本，不要先删除再建立第二份。手动安装的副本需要手动更新。

## 本地数据与备份

关系、粉丝和友人档案按当前登录账号 UID 隔离，保存在用户脚本本地存储。清除存储、卸载脚本或迁移浏览器前，请先导出备份。

Backup v3 包含关系雷达、粉丝快照与变化事件、手写友人档案；不包含登录凭据、环境偏好、访问足迹或计步器。恢复要求 owner UID 一致，先验证并展示替换预览，再由用户确认。它替换备份覆盖的模块，不做合并。

备注与标签只保存在当前浏览器，备份和私信导出均为明文文件，请妥善保管。没有跨设备自动同步。

## 支持范围与限制

- 面向桌面微博网页，Mobile Safari、iPhone 和 iPad 微博网页暂不支持。
- 主页新建档案支持 `/u/<UID>` 路由；信息流入口支持首页和原生“最新微博”，不覆盖搜索、评论区或私信。
- 关系与粉丝快照仅代表 API 可见结果；私信导出也不能保证包含接口未返回的内容。
- 切换微博账号后请刷新页面。
- 页面增强依赖微博结构，不能保证适配所有布局或浏览器。遇到身份证据不足时会跳过。
- 使用统计和访问足迹为本地估算与记录，不是完整行为档案。
