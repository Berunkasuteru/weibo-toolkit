# 发布前的真实页面检查

自动测试和模拟页面覆盖不到真实微博页面。每次发布前，用已登录的桌面浏览器照着这张表走一遍，大约十分钟。任何一项不符合预期，先记下页面类型和浏览器，再决定是否发布。

检查时不需要发送真实的移除请求，第 5 节走到确认框为止。

## 1. 启动与首页

- [ ] 打开 `https://weibo.com/`，右下角出现 **Weibo Toolkit** 按钮。
- [ ] 点开首页面板，四张卡片和“备份与设置”都在，没有横向滚动条。
- [ ] 按 Esc 关闭面板，焦点回到按钮上。
- [ ] 把窗口缩到一半宽度，面板没有被裁掉的内容。

## 2. 关系雷达与粉丝快照

- [ ] 点 **立即更新**，进度页的数字在变化，吃豆人在动。
- [ ] 更新过程中关闭面板再打开首页，按钮变成 **查看进度**，点它能回到进度页。
- [ ] 更新完成后显示结果，数字与微博显示的关注数大致相符。
- [ ] 点 **更新粉丝快照**，中途点 **取消**，几秒内显示已取消。
- [ ] 打开 **查看事件**，同一个账号只占一张卡片。

## 3. 友人档案

- [ ] 打开一个他人主页 `/u/<UID>`，在友人档案里为当前主页写一条备注并保存。
- [ ] 编辑时不保存直接点 **关闭**，出现确认提示。
- [ ] 开启 **在主页显示友人档案**，该主页上出现档案面板，位置不遮挡主页内容。
- [ ] 开启 **在信息流显示友人档案**，首页和“最新微博”的作者旁出现书签；有档案的是实心，没有的是空心。
- [ ] 点书签，卡片出现在作者附近，没有超出窗口。
- [ ] 把微博切到深色模式，书签和卡片仍然看得清。

## 4. 浏览体验

- [ ] 逐个打开 **净化** 页签里的开关，对应的页面组件消失；关闭后恢复。
- [ ] 打开 **隐藏信息流中的推广内容**，滚动几屏，信息流没有跳动或留下空白块。
- [ ] 打开 **显示主页小档案**，访问一个他人主页，小档案出现在预期位置。

## 5. 粉丝体检

- [ ] 设置筛选条件，结果数量合理。
- [ ] 把当前条件存成方案，清空条件后再选这个方案，条件恢复。
- [ ] 点 **选择当前页**，翻页后回来，勾选还在。
- [ ] 点 **按顺序选满**，提示里说明了有多少个不在当前页。
- [ ] 你也关注的人和写过友人档案的人，卡片上有“批量选择会跳过”的说明，并且没有被上面两种方式选中。
- [ ] 换一种 **排序**，列表顺序变化，已选清空。
- [ ] 打开 **移除记录**，能看到 v0.11.0 之后移除的账号；有记录时搜索一个昵称能找到。
- [ ] 点 **移除所选粉丝**，确认框列出完整名单，按钮上写明数量。**点取消，不要确认。**
- [ ] 底部操作栏贴着面板下沿，下方没有露出卡片内容。

## 6. 私信导出

- [ ] 打开一个普通的一对一会话，**导出 Markdown** 按钮出现在会话顶部，没有遮住微博自己的按钮。
- [ ] 导出一个较短的会话，文件内容与会话一致。

## 7. 备份

- [ ] **导出备份**，得到 JSON 文件。
- [ ] **恢复备份** 选刚才的文件，预览里的数字与当前一致。**点返回，不要确认。**
