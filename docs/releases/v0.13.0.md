# Weibo Toolkit v0.13.0

Adds unified sequential updates, `Backup v4` across all seven local storage domains, Friend Note integration across lists and Follower Hygiene, and filtered CSV/Markdown exports.

## Highlights

- **Unified Update All:** Added **Update All** on Home to run Friend Radar and Follower Snapshot sequentially in a two-step progress view with per-stage cancellation (cancelling Step 2 keeps the saved Friend Radar snapshot), shared concurrency locks across manual/automatic scans and restores, background result retention, and a merged summary view.
- **Backup v4:** Expanded backups to cover all seven per-UID storage domains—Friend Radar, Follower Snapshot, Friend Notes, Follower Removal Log, Follower Hygiene Presets, Usage Stats, and Profile Visits—with explicit `null` domain previews, rollback/uncertainty reporting, and backward compatibility for `v1`–`v3` backups.
- **Follower Hygiene filters, sorting & fail-closed note protection:** Added filters for Friend Note status, Friend Note tags, minimum follower/post counts, and registration cutoff; descending sorts by follower and post counts (missing values last); inline Friend Note summaries; and fail-closed gating when Friend Notes storage is unreadable.
- **Events, Overview, Friend Notes & exports:** Added event type and unread filters plus card/detail quick mark-as-read on Relationship Events; added event type filters on Follower Events; extended search across note text and tags; added direct UID lookup/creation in Friend Notes; and added UTF-8 BOM CSV and Markdown table exports with formula neutralization for Friend Notes, Relationship Overview, and Follower Events.
- **Feed bookmarks & PM export filenames:** Streamlined feed bookmarks into a compact icon-only trigger (retaining noted/historical-nickname indicators and floating cards without inline layout jitter), and added sanitized participant labels or UIDs to exported private-message Markdown filenames.

## Upgrade & Verification

Update in place and refresh Weibo. Existing `v1`–`v3` backups remain restorable without altering domains they predate. Verified with `node scripts/build-userscript.mjs --check` and all 13 offline test suites in `node tests/run.js`.
