# Weibo Toolkit v0.10.1

这次更新打磨工具箱界面，并修复多标签页更新、备份恢复和扫描取消的边界问题。友人档案、关系雷达、粉丝工具和私信导出的功能范围保持不变，备份继续使用 Backup v3。

## 界面与介绍

- 首页按关系雷达、粉丝变化、友人档案和浏览体验分组，备份与设置集中显示。
- 统一深浅色主题、字号、按钮、表单和浮层；改善事实分组、空状态、未读标记和扫描状态显示。
- 信息流中已有档案使用实心书签，与未建立档案的入口区分。
- 补齐面板的 Tab、Esc 和焦点恢复，以及浏览体验页签的方向键操作；正在输入时延后自动通知。
- 重写 GitHub 和 Greasy Fork 介绍，并保留本地访问记录、覆盖恢复及不可撤销操作的告知。本次 GitHub 发布不同时更新 Greasy Fork 页面。

## 可靠性修复

- 关系雷达在扫描开始时记录快照基线，拒绝其他标签页已经更新或恢复快照后的旧结果；扫描期间标记已读仍与新事件合并。
- 雷达状态无法读取时，工具箱和设置页局部显示错误，其余入口保持可用。原始损坏字符串仍与预览一致时，可经验证和确认用备份替换；无法读取的值继续拒绝处理。
- 关注和粉丝读取增加 30 秒请求期限，覆盖响应正文读取；粉丝取消可中断请求，并在取得存储锁、写入前再次检查。
- 手动扫描结束后不再替换用户后来打开的面板。恢复执行期间锁定面板关闭和替换，避免迟到的结果覆盖新的编辑内容。
- 修正计步器入口的提示参数、主页小档案主题刷新和事实行分组识别。

## 升级与边界

在原有用户脚本上更新并刷新微博，保留脚本名称与 namespace，无需删除重装。升级不改变存储键、数据格式或 Backup v1/v2/v3 的覆盖含义；跨设备或清除存储前请先导出备份。

请求期限只用于关注和粉丝读取，不适用于移除粉丝 POST。移除仍需确认、限量顺序执行、不自动重试，结果无法确认时停止。

恢复执行期间的面板锁没有超时；状态锁长期无法取得时需等待或刷新页面。普通关闭、返回及离开页面的未保存草稿限制仍存在，本次不宣称保护所有退出路径。

## 验证

本版经过源码与构建产物一致性、公开测试和版本更新记录检查。关键并发、损坏恢复和面板锁定有回归检查；取消与面板交互也经过隔离的模拟场景复验。

本轮尚未完成真实登录微博页面中的新 UI、完整恢复流程及全面跨浏览器验收。模拟页面和公开测试不代替实际页面验证。
