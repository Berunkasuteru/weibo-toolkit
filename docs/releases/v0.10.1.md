# Weibo Toolkit v0.10.1

Refines the Toolkit UI and hardens multi-tab scan concurrency, damaged-state recovery, and follower scan cancellation.

## Highlights

- **Modular Home & theme polish:** Grouped the Home panel by module with unified light/dark theme tokens, keyboard focus restoration (`Tab` / `Escape` / arrow keys), and solid vs. hollow feed bookmark icons.
- **Scan concurrency & deadlines:** Friend Radar records the baseline snapshot at scan start and rejects stale writes if another tab updated or restored state in the meantime. Following and follower reads enforce a 30-second per-page deadline, and follower cancellation re-checks before committing under the storage lock.
- **Damaged-state recovery & panel locks:** Unreadable radar state is isolated without blocking the rest of the Toolkit, and can still be replaced via a verified backup restore. Panels stay locked while a restore is in flight.

## Upgrade & Verification

Update in place and refresh Weibo. Storage keys, schemas, and `Backup v3` compatibility are unchanged. Verified with build consistency checks and offline concurrency/recovery test suites.
