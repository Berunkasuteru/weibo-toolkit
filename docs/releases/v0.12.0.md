# Weibo Toolkit v0.12.0

本版补上当前关注名单的浏览与筛选、粉丝变化搜索，以及微博计步器的阶段汇总；同时改进友人档案的返回路径、未保存修改保护和工具箱界面。

## 关系概览与粉丝变化

- 关系概览新增最新快照中的可见关注名单，可筛选全部、互相关注或单向关注，并按昵称、微博备注或 UID 搜索。名单分批加载，可继续加载更多。
- 从关注名单可打开对方主页、友人档案或已有的关系时间线。
- 粉丝变化新增昵称或 UID 搜索，以及打开主页、写友人档案的快捷入口。清除事件仍只影响本地记录。
- 从关系概览、关系事件或粉丝变化进入档案与时间线后，可返回原入口，并保留原来的筛选或搜索条件。关系事件全部标为已读后也保留搜索条件。

名单和关系状态来自最新成功快照，只覆盖接口可见结果，不代表实时关系或完整关注列表。

## 微博计步器

- 新增含今日的近 7 天、近 30 天活跃时间与浏览条数汇总。
- 新增可展开的历史每日明细，按日期倒序显示有活动的日期，沿用最多保留 90 天的规则。
- 阶段浏览条数按日累计：当天按微博去重，同一条微博在不同日期浏览会分别计入。

计步器仍需主动开启，数据只保存在当前浏览器，不进入备份。

## 界面与交互

- 调整深浅色主题、字体、控件、卡片和焦点样式，私信导出控件增加随容器宽度收缩的约束。
- 切换工具箱面板时也检查档案未保存修改。拒绝离开后保留原草稿与编辑状态；保存或删除进行中仍不能离开。
- 工具箱面板打开时，Esc 不再同时关闭底层的历史昵称浮层或信息流档案卡片。
- 自动更新失败时优先展示已识别的具体原因，正确提示请求超时、请求安全上限和浏览器锁不可用；未识别的原因回退到失败类别说明。

## 升级与数据

在原有用户脚本上更新并刷新微博即可。脚本名称、namespace、已有存储键和数据格式保持不变，无需迁移数据。备份仍为 Backup v3，继续兼容 v1/v2/v3。

## 验证范围与待验收项

- `node scripts/build-userscript.mjs --write` 已重新生成用户脚本，源码与产物逐字节一致。
- `node tests/run.js` 的 12 组公开测试全部通过，`node --check weibo-toolkit.user.js` 语法检查通过。
- 本次代码审阅还使用现有模拟 DOM 核对了 65 个关注账号的分批加载、筛选后进入档案再返回、拒绝离开时保留草稿、粉丝事件搜索与返回及单条清除，以及计步器跨月的日期边界。没有发送网络请求或真实移除请求。
- 本次代理验证未覆盖真实登录微博页面，真实页面由维护者自行验收。可按 [发布检查表](https://github.com/Berunkasuteru/weibo-toolkit/blob/v0.12.0/docs/RELEASE_CHECKLIST.md) 核对，重点包括深浅色、窄窗口、档案编辑与返回、私信按钮位置，以及移除确认框和停止入口的可见性。涉及批量执行的验证使用请求替身，无需为验收实际移除粉丝。
- 本地逻辑检查不能证明真实微博布局、极窄私信窗口或完整跨浏览器兼容性，本版不将这些环境列为已由代理验证。
