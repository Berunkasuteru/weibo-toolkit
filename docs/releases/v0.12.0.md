# Weibo Toolkit v0.12.0

Adds browsable following lists in Relationship Overview, Follower Event search, 7-day/30-day Stepmeter summaries, and improved Friend Note navigation.

## Highlights

- **Relationship Overview & Follower Events:** Browse API-visible following accounts from the latest snapshot, filter by all/mutual/one-way, and search by nickname, Weibo remark, or UID. Follower Events now support nickname/UID search and direct profile/note shortcuts, with filter state preserved when returning from timelines or notes.
- **Stepmeter summaries:** Added 7-day and 30-day active time and post-count summaries (including today) plus an expandable 90-day daily history breakdown.
- **UI & safety refinements:** Refined light/dark theme tokens and PM export width constraints, added unsaved-note prompts when switching Toolkit panels, prevented `Escape` in a modal panel from closing underlying popovers, and surfaced specific automatic-update failure reasons.

## Upgrade & Verification

Update in place and refresh Weibo. Storage keys, schemas, and `Backup v3` compatibility are unchanged. Verified with build consistency checks and 12 offline test suites.
