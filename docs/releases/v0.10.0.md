# Weibo Toolkit v0.10.0

Introduces **Friend Notes** (private UID-bound notes and tags), optional profile and feed note surfaces, and `Backup v3`.

## Highlights

- **Friend Notes:** Save private notes and tags bound to stable Weibo UIDs. Notes survive nickname changes and never merge same-name accounts. Browse, search, filter by tag, edit, and delete notes in the Toolkit manager.
- **Optional profile & feed surfaces:** View and edit notes directly on `/u/<UID>` profile pages or via lightweight author bookmarks on the home and latest feeds (including reposts without commentary). Both options are off by default.
- **Draft & concurrency protection:** Opening a bookmark starts in view mode. Cross-tab stale writes report conflicts instead of overwriting newer edits; IME composition `Enter` keys do not prematurely submit tags or saves.
- **Backup v3:** Covers Friend Radar, Follower Snapshot, and Friend Notes. Restoring legacy `v1` or `v2` backups leaves existing Friend Notes untouched.

## Upgrade & Verification

Update in place and refresh Weibo. Friend Notes make zero network requests and stay in local userscript storage. Verified with build consistency checks and offline test suites for note storage, concurrency, Backup v3, and feed/profile surfaces.
