# Weibo Toolkit v0.10.0

友人档案现在可以在信息流里用了。为微博上的人留下自己的备注与标签，刷到他时点开作者旁的小书签，就能找回这份本地记忆。

## 新增

- **友人档案**：按稳定 UID 保存私人备注与标签；改名不会切断档案，同名账号不会合并。工具箱支持搜索、标签筛选、查看、编辑和删除。
- **可选主页显示**：在他人的 `/u/<UID>` 主页上查看和编辑，默认关闭。
- **可选信息流书签**：支持首页和原生“最新微博”，优先放在外层作者昵称旁，包括没有评语的纯转发。备注正文与本地昵称记录收在卡片里。
- **Backup v3**：备份关系雷达、粉丝模块与友人档案。恢复 v1/v2 时保留它们没有覆盖的友人档案。

## 交互与数据保护

- 点击书签默认先查看，主动选择添加或编辑后才进入表单；没有实际修改时可直接关闭。
- 同页保存后更新相关查看界面，另一处正在编辑的草稿保留；跨标签的过期编辑会提示冲突。
- 输入法组词期间的回车不添加标签、不保存。
- 卡片内容过高时内部滚动；原微博被复用或移除后，有修改的草稿停靠在窗口内，仍保存到最初确认的 UID。
- 点击入口时重新校验作者，避免按帧协调尚未完成时打开旧作者的档案。

## 如何使用

升级并刷新微博，在工具箱首页打开 **友人档案**。如需页面入口，进入 **浏览体验 → 增强**，按需开启“在主页显示友人档案”或“在信息流显示友人档案”。两项互相独立，默认关闭。

## 升级与范围

在原有用户脚本上更新，保留脚本名称与 namespace，不需要删除重装。建议升级前导出备份；备注与标签会进入本地明文 Backup v3，请妥善保管。旧版本不能恢复 v3 文件，旧 v1/v2 文件在本版仍可恢复。

友人档案不新增微博请求，不记录作者浏览轨迹，不上传内容，也不修改真实微博关系。昵称和关系记录仅来自 Toolkit 实际保存的观察；页面增强不能保证适配微博的所有布局。

## 验证

发布候选经过源码与产物一致性、JavaScript 语法及公开测试验证。新增功能包含数据与并发、备份、主页及信息流回归；用户已在真实微博页面试用，并提供纯转发昵称节点用于修复。完整的 Tampermonkey 跨浏览器、输入法与全部微博页面结构验证仍未完成，不作全面兼容性承诺。
