# Weibo Toolkit v0.10.2

Fixes narrow-viewport panel layout issues and expands manual Follower Hygiene batch selection to up to 200 accounts per batch.

## Highlights

- **Cross-page batch selection (up to 200):** Manual selections persist across pagination (50 cards per page) up to 200 accounts per batch; changing filters clears selections.
- **Batch confirmation & execution guards:** The confirmation dialog lists every selected account, invalidates stale confirmations if selection or eligibility changes, re-verifies the list before execution, and locks panel exit while keeping the stop control reachable.
- **Responsive layout fixes:** Panels grow with content within viewport bounds; the hygiene selection bar docks to the bottom with dynamic scroll padding, and long nicknames, error codes, tabs, and popovers wrap cleanly in narrow windows.

## Upgrade & Verification

Update in place and refresh Weibo. Storage keys, schemas, and `Backup v3` compatibility are unchanged. Verified with build consistency checks, 12 offline test suites, and synthetic batch-removal/viewport checks.
