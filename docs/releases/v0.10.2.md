# Weibo Toolkit v0.10.2

本版修正工具箱面板和窄窗口布局，并把粉丝体检的手动批量选择扩展到每批最多 200 个。`v0.10.1` 的 GitHub Release 曾因界面问题撤下；本版在其代码基础上完成修复，升级自 `v0.10.0` 时也会获得此前的界面、扫描与恢复改进。

## 粉丝体检与批量移除

- 每页仍显示 50 条，翻页保留手动选择，每批最多 200 个。修改筛选条件会清空选择；没有“选择全部筛选结果”或后台自动移除。
- 确认框列出全部已选账号。选择或账号状态变化会作废旧确认，执行前再次核对名单，排除已移除和结果待确认的账号。
- 批量执行期间保护面板关闭与替换，保持进度和停止入口可见；忙碌时不能改变选择，迟到的旧选择事件也不会修改计划。
- 移除仍需主动确认，逐个执行，成功后约等待 3 秒，不自动重试；失败、结果不确定或用户停止后不再发送剩余请求。

## 界面修复

- 长面板随内容增长，并受窗口高度限制；粉丝体检操作栏贴底显示。
- 滚动预留随操作栏实际高度更新，窗口缩窄后确认按钮仍停在底栏上方；面板关闭或替换时清理高度监听。
- 修复长昵称、档案卡片、批量底栏提示、错误码和设置页签在窄窗口中溢出的问题；历史昵称浮层宽度受视口限制。
- 极窄窗口的标题单独成行，最多显示三行，保留返回和关闭按钮空间。
- 调整事实卡片与事件行；扫描进度采用吃豆人动画，减少动态效果偏好下停止动画。
- GitHub 与 Greasy Fork 介绍文件同步新的批量范围。本次 GitHub 发布不同时更新 Greasy Fork 页面。

## 升级与已知限制

在原有用户脚本上更新并刷新微博即可，无需删除重装。脚本名称、namespace、存储键和数据格式保持不变，备份仍为 Backup v3，继续兼容 v1/v2/v3。

**移除粉丝 POST 仍没有请求期限。** 停止只阻止后续请求，不撤回已经发送的操作；当前请求挂起时，面板退出锁会保持。200 个账号仅成功间隔的等待就约需 10 分钟，实际完成时间取决于接口响应，不保证微博允许持续执行这么多操作。

私信导出控件的极窄窗口适配暂缓，等待真实私信页验收。

## 验证范围

- 源码与构建产物一致性通过，12 项公开测试通过。
- 使用实际产物、合成数据和请求替身验证跨页选择、执行保护、停止与确认名单核对；没有发送真实移除请求。
- 浏览器机器检查发现的七类布局问题经过定向复验；补测了窗口缩窄和监听清理。完整 245 个组合没有在最终修复后再次运行。
- 尚未完成真实登录微博页面、真实批量移除、完整恢复流程及全面跨浏览器验收。模拟检查不代替实际页面验证。
