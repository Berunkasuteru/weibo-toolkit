# Weibo Toolkit v0.11.0

本版围绕粉丝体检的实际使用做了一轮强化：可以连续处理多批、保存常用筛选条件、按粉丝数、公开微博数或注册时间排序，并为不可撤销的移除操作补上了保护名单和本地记录。另外改进了手动更新、关系事件和友人档案编辑的几处交互。

## 三处行为变更

升级前请先了解这三点，它们改变了批量移除的选择方式。

- **“按顺序选满”可以选中你没有翻到的账号。** 它按筛选结果的顺序跨页选择，直到每批上限 200 个，并提示其中有多少个不在当前页。确认框仍然列出完整名单。
- **已移除的账号不再列出。** 成功移除的账号会从粉丝体检的结果里隐藏，关闭面板或刷新页面后依然如此，直到下一次更新粉丝快照。隐藏的依据是 Toolkit 自己记录的“已确认移除”。
- **批量选择会跳过受保护的账号。** “选择当前页”和“按顺序选满”不再选中快照中你也关注的账号，以及你写过友人档案的账号。这些账号仍然可以逐个勾选，确认框会注明原因。友人档案无法读取时，保护降级为只按关注关系跳过，页面会显示警告。

## 粉丝体检

- 新增筛选方案：常用的筛选条件可以命名保存，每个账号最多 8 个。并发保存会保留其他方案；本面板尚不知道的同名方案会提示冲突，不直接覆盖。
- 新增排序：按粉丝数、公开微博数或注册时间排列结果。数值未知的账号排在最后。
- 一批全部成功后，结果汇总里可以直接“选满下一批并预览”。被用户停止、出现失败或结果不确定的批次不提供这个入口。
- 新增移除记录：成功移除后会尽力把账号的昵称、UID 和时间写入本地记录，可以搜索和导出 CSV，最多保留最近 5000 条。记录写入失败不影响移除本身。
- 打开确认框和最终确认时都会重新核对保护状态，名单的标注有变化时重新预览。
- 批量移除中，某个账号的操作超过 20 秒仍未完成时会提示：可以继续等待；刷新页面会立即退出，但那一个账号的结果将无法确认。
- 确认框提示保持标签页在前台。切到后台后，浏览器可能延后计时，批量可能变慢。
- 窗口较窄（不超过 360px）或较矮（不超过 520px）时，选择阶段的操作栏不再悬浮，改为排在列表末尾，避免遮住确认按钮。批量执行期间它仍然贴底悬浮，停止按钮始终可见。

移除仍需每批确认，逐个执行，成功后约等待 3 秒，不自动重试；失败、结果不确定或用户停止后不再发送剩余请求。每批上限仍是 200 个，没有后台自动移除。

## 其他改进

- 手动更新进行中，首页按钮变为“查看进度”，可以回到进度页；粉丝扫描在那里仍可取消。离开进度页之后才完成的更新，结果会留在首页对应卡片上等待查看。这些状态只在当前页面内有效，刷新后不保留，并且只对发起更新的账号可见。
- 关系事件按账号归并，一个账号一张卡片，显示最新一条；其余事件在该账号的时间线里。可以从事件卡片直接写友人档案。
- 工具箱里的友人档案有未保存修改时，关闭或返回前先确认。保存或删除进行中不能离开，以免出现“选择放弃却仍然保存”的情况。
- 新增 `docs/RELEASE_CHECKLIST.md`，列出发布前需要在真实微博页面上手动核对的项目。

## 升级与数据

在原有用户脚本上更新并刷新微博即可，无需删除重装。脚本名称、namespace 和已有存储键保持不变，备份仍为 Backup v3，继续兼容 v1/v2/v3。

本版新增两项本地数据，都按微博账号分开保存在当前浏览器，**不进入备份**：

- 筛选方案；
- 移除记录。

移除记录从本版开始写入，此前的移除不在其中。它是明文，包含账号昵称和 UID；需要带走时请导出 CSV。本版没有提供清空移除记录的入口。

## 已知限制

- 移除粉丝的请求仍然没有期限。停止只阻止后续请求，不撤回已经发送的操作；批量期间面板保持锁定。
- 移除记录的时间是成功后发起写入时的本机时间，不是微博端执行移除的时间。
- 保护名单中的“你也关注”依据的是粉丝快照，不是实时状态。
- 连续多批是否会触发微博的限制没有验证。遇到失败会自动停止。
- 浏览器对后台标签页计时的影响没有针对本工具实测。
- 私信导出控件的极窄窗口适配仍然暂缓，等待真实私信页验收。

## 验证范围

- 源码与构建产物一致性通过，12 项公开测试通过。粉丝体检的界面测试新增了连续批次、按顺序选满、筛选方案的并发保存、保护名单及其状态变化、排序和移除记录的检查。
- 使用实际产物、合成数据和请求替身，在本地模拟页面中核对了关键界面流程，并经过多轮独立的定向复验。没有发送真实移除请求，没有产生真实下载。
- 已完成 1000×800、560×320、320×568、240×420 四种本地模拟视口的选择态与执行态布局检查。确认按钮及执行期间的停止按钮在所测滚动位置、长昵称和长等待提示状态下均可命中；点击停止并放行当前假请求后，没有发送下一条请求。
- 尚未完成真实登录微博宿主页面、真实连续批量移除、其他尺寸及完整跨浏览器验收。模拟检查不代替实际页面验证。
