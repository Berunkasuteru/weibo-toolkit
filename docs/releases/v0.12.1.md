# Weibo Toolkit v0.12.1

This release refines scan control, list navigation, filter responsiveness, and private-message export reliability while preserving all existing storage schemas and backup compatibility.

## Scans, Navigation & Filtering

- **Cancellable Friend Radar scans & old-name search:** Manual Friend Radar updates can now be cancelled mid-scan (including during inter-page delays) without modifying stored snapshots or generating events. Relationship event search now also matches previous nicknames (`previous.screenName`) on rename events.
- **Context & scroll restoration:** Returning from detail views, relationship timelines, Friend Notes, or the removal log now restores the active search/filter state, expanded item count, and scroll position across Relationship Events, Follower Events, Relationship Overview, Friend Notes Manager, Follower Hygiene, and Removal Log.
- **Follower Hygiene workflow:** Added a filter reset button, `160ms` input debounce (automatically flushed before bulk selection, batch review, or child-view navigation), direct profile and Friend Note actions on hygiene and removal-log cards, and preserved quarantine state (`uncertainRemovalUids`) across child-view round trips.

## UI, Export & Reliability

- **Instant settings & inline confirmation:** Automatic update intervals now save immediately on selection and revert the control if persistence fails. Clearing Stepmeter history now uses an inline confirmation instead of a blocking browser `confirm()`.
- **Private Message export & Backup picker:** Fixed startup ordering on `api.weibo.com/chat*` so shared theme and unload state initialize before the export module runs. Added dark/system theme support and a 30-second per-page timeout to PM export, quiet stream abort on write failure, and non-destructive inline status when cancelling backup file pickers.
- **Performance & safety guards:** Replaced repeated per-UID local-fact scans with a single linear index (`buildProfileLocalFactsIndex`), capped stored profile visits at 2,000 entries per account under an exclusive lock, added previous-nickname indicators on feed bookmarks, and enabled on-demand `beforeunload` protection while exports, removals, or unsaved note drafts are active.

## Upgrade & Data Compatibility

Update the userscript in place and refresh Weibo. Script name, namespace, storage keys, and schemas are unchanged. Backups remain `Backup v3` and continue to accept `v1`, `v2`, and `v3` files.
