# Weibo Toolkit v0.12.1

Refines scan cancellation, list navigation context restoration, Follower Hygiene responsiveness, and Private Message export reliability.

## Highlights

- **Cancellable Friend Radar scans & old-name search:** Cancel manual Friend Radar updates mid-scan (including during inter-page delays) without modifying stored snapshots. Relationship Event search now also matches `previous.screenName` on rename events.
- **List state & scroll restoration:** Returning from detail views, timelines, Friend Notes, or the removal log restores active search/filter criteria, expanded item count, and scroll position across Relationship Events, Follower Events, Relationship Overview, Friend Notes Manager, Follower Hygiene, and Removal Log.
- **Follower Hygiene workflow:** Added a filter reset button, `160ms` input debounce (automatically flushed before selection, review, or child-view navigation), profile/note shortcuts on hygiene and removal-log cards, and preserved quarantine state (`uncertainRemovalUids`) across child views.
- **Settings, PM Export & safety guards:** Auto-update intervals now save immediately on selection; Stepmeter history uses inline confirmation; PM export initializes shared theme/unload state before running and adds dark/system theme support plus a 30s per-page timeout; profile local-fact lookups use a linear index (`buildProfileLocalFactsIndex`); profile visits cap at 2,000 entries under an exclusive lock; and `beforeunload` guards active exports, removals, and unsaved drafts.

## Upgrade & Verification

Update in place and refresh Weibo. Storage keys, schemas, and `Backup v3` compatibility are unchanged. Verified with `node scripts/build-userscript.mjs --write` and all 13 offline test suites in `node tests/run.js`.
